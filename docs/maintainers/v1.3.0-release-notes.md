# shin-wallslice 1.3.0 — Automatic OLEDify recommendations

Each accepted wallpaper now gets fresh OLEDify defaults from a deterministic local
check of the full oriented sRGB source. Images qualify when at least **15%** of
visible pixels have **all three RGB channels at or below 32**, including both
boundaries. Fully transparent pixels are excluded. Candidates start on at cutoff
**16**; other images start off at 16. This percentage is a heuristic, not a measured
device-energy saving.

When AI is enabled, candidates automatically receive a bounded vision-guided
binary search over cutoffs 0–255. Each evaluation submits the original composition
and an actual OLEDified trial. The highest evaluated acceptable cutoff is used;
if no effective conversion is acceptable, OLEDify is recommended off. Naming and
subject detection remain independent. AI remains disabled by default.

Local defaults keep previews, PNG/ZIP downloads, and configured server saving
usable while analysis runs or fails. One recommendation applies across device
outputs. Editing the switch or cutoff protects both settings for the current
image, even if restored to their initial values. Late results and Retry never
overwrite manual choices. Feedback clearly separates the local fallback from
completed AI recommendations; failures offer an explicit bounded Retry.

## Configuration and upgrade

Install/update: [README](https://github.com/jmdarling/shin-wallslice#get-started)
and [Unraid guide](https://github.com/jmdarling/shin-wallslice/blob/main/docs/unraid.md).
Image: `ghcr.io/jmdarling/shin-wallslice:1.3.0`, with aliases `:1`, `:1.3`, and
`:latest`. Publication does not update running installations automatically.
Retain the same persistent data and optional output mounts when recreating.

New runtime settings, supporting partial read-only JSON and environment overrides:

| JSON setting                | Default | Range and environment override                                                                   |
| --------------------------- | ------- | ------------------------------------------------------------------------------------------------ |
| `oledMinimumDarkPercentage` | 15      | Finite 0–100 percentage points, fractions allowed; `SHIN_WALLSLICE_OLED_MINIMUM_DARK_PERCENTAGE` |
| `oledNearBlackCutoff`       | 32      | Integer 0–255; `SHIN_WALLSLICE_OLED_NEAR_BLACK_CUTOFF`                                           |
| `oledMaxVisionRequests`     | 8       | Integer 1–8 per attempt; `SHIN_WALLSLICE_OLED_MAX_VISION_REQUESTS`                               |

Restart after configuration changes. Existing settings remain compatible. Saved
OLEDify preferences no longer override new-image defaults; other preferences keep
their behavior. Roll back to 1.2.0 by removing these three JSON keys and their
environment overrides, then recreate with the existing data/output mounts. Older
versions reject the new JSON settings. No database or additional container is
required; Node.js 24, non-root execution, and Linux amd64/arm64 remain supported.

## AI privacy and limitations

Only local candidates trigger this additional AI task. Each search or Retry can
submit up to eight original/trial pairs, increasing provider cost and latency.
Your configured OpenAI-compatible vision service must support two image inputs
and the requested JSON judgment. Comparison images use the full composition,
bounded to 1024 × 1024, with lossless shadow preparation rather than the naming
JPEG. Requests time out after 30 seconds; a search attempt is capped at 270 seconds
plus up to 30 seconds of initial upload preparation. There is no automatic retry
loop. AI-disabled installations make no vision requests.

AI judgment is best effort, not a guarantee of a globally optimal cutoff or
artifact-free results. Live artwork, photography, and gradient/edge review found
that the provider sometimes accepted visible hard transitions and lost detail.
Inspect previews and use manual controls as needed. The
[verification notes](../design/v1.3.0/README.md) distinguish actual provider trials
from deterministic transport/search fixtures and record the observed artifacts.
