[Unraid guide](https://github.com/jmdarling/shin-wallslice/blob/main/docs/unraid.md).

Both runtime architectures and their SBOM/provenance attestations are verified anonymously.

Changes: verified release/CI workflows, native amd64/arm64 container checks,
Unraid installation template and bounded first-run appdata initialization,
Community Applications submission materials, and optional owner issue-to-PR automation.
Wallpaper features are unchanged.

Compatibility: Node.js 24, one Fastify process/port (3000), flat-file `/data`
preferences, non-root UID/GID 1000. Existing UID 1000 data remains usable. Unraid's
initializer briefly starts as root to prepare only the dedicated data mount, then
drops privileges. Allow 4 GiB memory and 4 GiB writable temporary disk. Single-user
trusted-LAN application, AI disabled by default. CA listing is pending.
