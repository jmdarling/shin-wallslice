# shin-wallslice 1.0.1 — Unraid AI configuration fields

Adds advanced AI API URL, model, and masked token fields to the Unraid template,
with empty defaults and AI disabled. No variables need to be created manually.
Empty URL/model environment values preserve JSON/default settings. Enabling AI
still requires a valid endpoint and model; invalid nonempty settings fail clearly.
An empty token clears a JSON token, as before.

Install/update: [Unraid guide](https://github.com/jmdarling/shin-wallslice/blob/main/docs/unraid.md). Update existing installations before
using the refreshed template; 1.0.0 rejects empty URL/model environment values.
Keep the same appdata and port mappings. Wallpaper processing is unchanged.

Images: `ghcr.io/jmdarling/shin-wallslice:1.0.1`, aliases `:1`, `:1.0`, `:latest`.
The exact 1.0.0 artifact is preserved. The [GitHub Release](https://github.com/jmdarling/shin-wallslice/releases/tag/v1.0.1)
records the verified multi-platform digest, release run, and scan evidence.

Validation: configuration regression covers empty fields, inherited JSON,
missing enabled-AI settings, and whitespace rejection. Native architecture smoke
checks exercise the blank default template fields. Real NAS initial installation
passed by developer report; refreshed-template verification is pending.

Rollback: retain appdata and choose the previous exact image. Before returning to
1.0.0, remove blank AI URL/model variables from the saved container settings.
See [release operations](https://github.com/jmdarling/shin-wallslice/blob/main/docs/maintainers/releases.md) for metadata inspection and recovery.
