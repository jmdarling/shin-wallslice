# v0.7.0 — Visual crop method control

Status: implemented

Developer sign-off: approved on 2026-10-20 after reviewing the running application, including matching control sizes, increased horizontal spacing, and the “(entropy)” subtitle.

Update the Processing page's Crop method control to follow the supplied mockup and `ui.excalidraw`: a Smart tile beside a spatial corner-or-center selector. This is an appearance and interaction presentation update; existing crop calculations and workflow behavior remain unchanged.

## Feature: Smart tile and spatial position selector

Replace the text-heavy crop method options with two visually distinct controls under “Crop method.” Present a selectable tile labeled “Smart” with the same sparkle artwork used for the AI-assisted name indicator on Download. Beside it, show a rounded spatial selector with selectable top-left, top-right, bottom-left, bottom-right, and center targets arranged at their corresponding positions, with an “or” separator between the two controls where space allows.

Developer review clarification: Smart and the spatial selector must have matching square dimensions and a balanced placement within the form. Center the pair side by side where space allows, and stack matching squares on very narrow screens. Increase horizontal spacing around the “or” separator. Display “(entropy)” on a separate line below “Smart”; a future optional AI crop mode and “(AI)” subtitle are outside this release.

The mockups guide the composition rather than exact sizes, colors, or hand-drawn styling. The position selector's detailed design may be adapted to the application's Web Awesome design system, provided its five choices and active selection are clear.

### Acceptance criteria

- [x] Processing presents the Smart tile and spatial position selector together under “Crop method,” replacing the existing visible “Smart (entropy)” radio label and list of text anchor options. The tile's main visible label is “Smart,” with “(entropy)” beneath it.
- [x] The Smart tile uses the same sparkle artwork as the Download page's AI-assisted naming indicator. Reusing this artwork does not change Smart's existing local entropy-based cropping or make it depend on AI configuration or service availability.
- [x] The position selector presents exactly five selectable targets: four corner marks at their respective corners and a center mark in the middle. Selecting a target directly activates that anchor without requiring a separate mode switch.
- [x] Smart and the five anchors form one mutually exclusive selection. Smart is visibly selected when active; when an anchor is active, that specific target is visibly selected and Smart is unselected. A previously remembered anchor does not appear active while Smart is selected.
- [x] Every choice has an accessible name, exposes its selected state, and can be selected with the keyboard. Focus is visible, and selection is distinguishable without relying on color alone. Pointer and touch users can reliably select each target.
- [x] The controls fit the Processing sidebar on desktop and remain usable without horizontal overflow or overlapping targets at narrow mobile widths. Labels, targets, selection, and focus remain readable in both existing light and dark modes.

## Feature: Preserve crop workflow behavior

The redesigned controls retain the current global crop method semantics, manual device positioning, and flat-file preference behavior. This version introduces no new crop algorithms or anchor positions.

### Acceptance criteria

- [x] Selecting Smart restores the existing entropy-based starting crop for every selected device. Selecting a corner or center positions every selected device's crop at that source-image anchor, preserving the current crop dimensions and aspect ratios.
- [x] Changing the global method or anchor discards manual positions for selected devices and recalculates their crops, as before. Newly selected devices start from the active global choice.
- [x] Independent manual dragging and each device's Reset position continue to work: dragging one device does not move another, and Reset position restores only that device using the active global choice. Exported framing continues to match the final previews.
- [x] Existing saved crop method and anchor preferences display correctly in the new controls without migration or loss. The choice retains its existing persistence across navigation, Start over, new wallpapers, browser reloads, and application restarts with persistent data retained. First-use default remains Smart.
- [x] Lit Chromium browser tests verify selection of Smart and all five anchors, mutually exclusive state, keyboard operation and accessible names, restored preferences, and the existing global reset and per-device positioning behavior. Visual verification covers desktop and narrow mobile layouts in light and dark modes.
- [x] Root lint, formatting checks, explicit TypeScript checks, tests, and production builds pass.
